## 🚀 Principais Projetos

### 📱 [Memora](https://github.com/Edudu720) *(Projeto Integrador — Fatec Americana | Repositório Privado)*
Companheiro digital acessível que ensina pessoas idosas a usar o smartphone com autonomia e segurança contra engenharia social.
- **Back-end:** Java 21, Spring Boot, Spring Security (JWT + Refresh Token + Argon2id), Spring Data JPA, Flyway, PostgreSQL 16 (Docker / Neon) e integração com IA (Gemini).
- **Mobile:** Flutter + Dart (Clean Architecture, `dio`, cliente gerado via OpenAPI, `flutter_secure_storage`, MQTT para IoT/ESP32, OpenStreetMap/`flutter_map`).
- **Qualidade & Metodologia:** Spec-Driven Development (SDD), testes automatizados (`flutter test`, `mvnw test`, Testcontainers) e deploy containerizado (`Dockerfile` / Render).

### 🏢 Plataformas Internas & CRM — Sellmap *(Repositórios Privados)*
Desenvolvimento de plataformas web corporativas com foco em **CRM, funil comercial (Kanban), gestão de oportunidades, catálogo/estoque e integrações**.
- **Stack aplicada:** TypeScript, Next.js (App Router), React, Node.js, NestJS, Prisma ORM, Supabase (Auth & PostgreSQL), Zod, Tailwind CSS, filas assíncronas (BullMQ), Swagger/OpenAPI e webhooks (`HMAC-SHA256`).
- **Qualidade:** testes unitários, de integração, banco (pgTAP) e E2E com Vitest e Playwright.

### 🌌 [Cosmic Atlas](https://github.com/Edudu720/cosmic-atlas) · [Demo ao Vivo](https://edudu720.github.io/cosmic-atlas/)
Mapa galáctico 3D interativo construído com **JavaScript (ES Modules)**, **Three.js** e **Vite**.
- Consumo assíncrono paralelo de múltiplas APIs REST (SWAPI e Rick and Morty API) com cache em memória, algoritmo de anti-colisão 3D e pipeline CI/CD no **GitHub Actions** para **GitHub Pages**.

### 📊 [Dashboard de Salários na Área de Dados](https://github.com/Edudu720/imers-o-dados-panda)
Aplicação analítica interativa em **Python**, **Pandas**, **Streamlit** e **Plotly**, com filtros dinâmicos, KPIs e mapa coroplético.
